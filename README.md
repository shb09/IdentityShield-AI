## 🔍 What Is This?

> **IdentityShield AI** is an assistive screening platform that analyzes uploaded identity and travel documents and produces an **explainable risk assessment** — not a black-box decision.

```
 ┌──────────────┐     ┌──────────────┐     ┌─────────────────────────┐
 │   OFFICER    │────▶│   UPLOAD     │────▶│   MULTI-SIGNAL          │
 │  (human)     │     │   DOCUMENT   │     │   AI ANALYSIS           │
 └──────────────┘     └──────────────┘     └────────────┬────────────┘
                                                        │
                                          ┌─────────────▼─────────────┐
                                          │   EXPLAINABLE RISK SCORE   │
                                          │   0─30 LOW │ 31─60 MED    │
                                          │   61─100 HIGH              │
                                          └─────────────┬─────────────┘
                                                        │
                                          ┌─────────────▼─────────────┐
                                          │   OFFICER DECIDES          │
                                          │   (AI recommends, human    │
                                          │    has final say)          │
                                          └───────────────────────────┘
```

## ⚡ Quick Start

### Prerequisites

| Requirement | Install |
|-------------|---------|
| Python 3.10+ | [python.org](https://python.org) |
| Node.js 18+ | [nodejs.org](https://nodejs.org) |
| Tesseract OCR | `brew install tesseract` (macOS) / `sudo apt install tesseract-ocr` (Linux) |

### One-Click Start

```bash
git clone https://github.com/shb09/IdentityShield-AI.git
cd IdentityShield-AI
chmod +x start.sh
./start.sh
```

### Manual Start

```bash
# Terminal 1 — Backend
cd backend
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

# Terminal 2 — Frontend
cd frontend
npm install
npm run dev
```

## ⚖️ Risk Scoring Engine

### Score Ranges

```
   0          30          60          100
   ├──────────┼───────────┼────────────┤
   │   LOW    │  MEDIUM   │    HIGH    │
   │  🟢      │   🟡      │    🔴      │
   │ 12/100   │  50/100   │   85/100   │
   │ GENUINE  │  REVIEW   │  ESCALATE  │
```

### Configurable Weights

```python
RISK_WEIGHTS = {
    "document_validity":  0.20,  # Date checks, expiry, format
    "field_consistency":  0.20,  # OCR confidence, completeness
    "tampering":          0.30,  # Image forensics analysis
    "face_verification":  0.30,  # Document vs presented face
}
# Weights are tunable per deployment scenario
```
